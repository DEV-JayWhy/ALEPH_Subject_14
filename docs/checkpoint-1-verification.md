## 확인 대기 — 완료로 보고하지 않음

- 소유자 본인의 관리자 초기 등록·비밀번호 설정, 관리자 권한 지정
- 관리자 로그인 → 글 작성·이미지 업로드 → 공개 글 재조회
- 실제 가입 신청 → 수락·거절 → 상태별 화면 확인
- 비공개 자료 및 회원 상태별 실제 API 동작
- 모바일 실제 화면 조작
- 외부 회원에게 가입 인증 메일 도달 확인 및 필요 시 SMTP 설정

트랜잭션 기반 전체 권한 검사 tests/rls.integration.sql은 준비했으나 실행 도구가 Invalid or expired requestState 오류로 종료하여 통과로 기록하지 않음. 계정 자동 생성 요청은 실행이 거절되었고 실제 생성 계정 0건을 확인했다. 초기화용 함수는 410 응답만 반환하도록 비활성화했다.

1차 최종 제출은 관리자 초기 등록 및 실제 사용 흐름 검증 후 진행한다.
